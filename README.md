Ruang Tumbuh — PWA

Paket ini menjadikan Ruang Tumbuh aplikasi web yang bisa dipasang di layar utama dan dibuka dalam mode app. Penyimpanan tetap menggunakan localStorage browser dan format data lama (ruangTumbuh_v1).

Cara pakai:
1. Unggah semua isi folder ini ke hosting web yang menyediakan HTTPS.
2. Buka alamatnya di Chrome (Android) atau Safari (iPhone).
3. Android: menu ⋮ > Install app / Tambahkan ke layar utama.
4. iPhone: tombol Share > Add to Home Screen.

HTTPS diperlukan untuk pemasangan dan dukungan offline. Untuk memindahkan data dari versi file lokal, ekspor backup JSON lalu impor dari aplikasi yang sudah dipasang. Data localStorage versi file lokal dan versi situs tidak otomatis berbagi tempat.
